DR. D. MEGHANA & DR. P. CHINDU KUMAR
ENGAGEMENT INVITATION WEBSITE
=================================

PROJECT FILES
-------------
index.html   - Invitation content and page structure
style.css    - Blush pink and gold design, responsive layout
script.js    - Countdown, scratch reveal, language toggle and music control

PREVIEW LOCALLY
---------------
1. Download and extract this ZIP.
2. Open the extracted folder in Visual Studio Code.
3. Open index.html in your browser, or use the VS Code "Live Server" extension.
4. Internet is required for Google Fonts and the sample Unsplash photographs.

CUSTOMIZE PHOTOS
----------------
The portrait backgrounds are configured in style.css:
- .bride-photo
- .groom-photo

The three gallery photos are configured in index.html in the .gallery section.
Replace the sample image URLs with your own image paths, e.g. images/meghana.jpg.
Create an "images" folder and place your photographs inside it.

OPTIONAL BACKGROUND MUSIC
------------------------
Add an audio file named music.mp3 in the same folder as index.html.
Use music that you own or have permission to use. Guests must tap the music button
to start playback; the website does not autoplay audio.

PUBLISH WITH VERCEL
-------------------
1. Create a GitHub repository and upload index.html, style.css and script.js.
2. Sign in at https://vercel.com/ and choose Add New > Project.
3. Import your GitHub repository.
4. Choose "Other" if asked for a framework preset.
5. No build command is needed for this static HTML project.
6. Deploy. Vercel will provide a public link to share with guests.
